# Тестовый набор данных: «Первичка для анализа работа.xlsx»

## Файл

- Путь: `docs/Первичка для анализа работа.xlsx`
- Назначение: базовый “реальный” датасет для проверки полного цикла анализа и корректности отчётов.

## Цели анализа (что должно получиться)

### Первичные конечные точки

1) Двигательные функции: динамика УШОБ (UPDRS) часть 3
- Метрика: изменение суммарного балла между V1 и V6
- Сравнение: активное воздействие vs плацебо

2) Повседневная активность: динамика УШОБ (UPDRS) часть 2
- Метрика: изменение суммарного балла между V1 и V6
- Сравнение: активное воздействие vs плацебо

### Вторичные конечные точки

1) DASS-21: динамика депрессии/тревоги/стресса (суммарные баллы)
2) Эпуорт: дневная сонливость
3) Утомляемость и апатия: суммарные баллы шкал
4) Когнитивные функции: Stroop + Trail Making Test (интегральные/суммарные баллы)
5) PDQ-39: качество жизни
6) Безопасность: AE/SAE, динамика АД (сопоставимость между группами)

## Требуемые роли переменных в приложении

- Target/Outcome: любой из endpoint-дельт (например, `UPDRS3_delta_V6_V1`)
- Group/Factor: признак группы лечения (активное/плацебо)
- Covariates: базовые ковариаты (возраст, пол, длительность болезни и т.п. — если присутствуют)
- Repeated/Time (если есть визиты отдельными строками): пациент/визит (для mixed models)

## “Грязные” кейсы, которые должны выдерживаться

- Пропуски: пустые клетки в баллах/АД/опросниках
- Смешанные типы: числа в виде строк, запятые как разделитель дробной части
- Дубли: повторяющиеся строки пациента/визита
- Непредвиденные категории: редкие группы/подгруппы

## Ожидаемые артефакты

- Scan report: корректные типы колонок, missing_count/unique_count/top_values/mean
- Variable Workspace: назначение ролей без ошибок, подсказки по статистикам
- Analysis run: выполнение без “пустых кнопок”, получение результата/ошибок с human-readable текстом
- Export: PDF/DOCX/JSON (если включено в UI)
