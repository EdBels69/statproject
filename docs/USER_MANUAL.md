## Быстрый старт

1. Откройте <http://localhost:5173>
2. Загрузите Excel файл с данными
3. Перейдите в «Дизайн» для настройки анализа
4. Скачайте отчёт в Word/PDF/HTML

## Загрузка данных

### Поддерживаемые форматы

- **Excel** (.xlsx, .xls)
- **CSV** (.csv)
- **OpenDocument** (.ods)

### Как загрузить

1. Нажмите **«Загрузить датасет»** на главной
2. Выберите файл или перетащите его
3. Укажите строку заголовка (обычно 0)
4. Дождитесь автоматического сканирования

### Автоматическое определение

Система автоматически:

- Определит типы колонок (числовые, категориальные, даты)
- Найдёт группирующую переменную
- Обнаружит временные точки измерений
- Предложит подходящие методы анализа

## Подготовка данных

### Профиль переменных

После загрузки откройте **«Подготовка»** для:

| Действие | Описание |
|----------|----------|
| Изменить тип | Числовой → Категориальный и наоборот |
| Очистить | Заполнить пропуски (среднее, медиана, мода) |
| Логарифм | Применить log-трансформацию |
| Исключить | Убрать переменную из анализа |

### Обработка пропусков

- **Медиана** — для чисел с выбросами
- **Среднее** — для нормальных распределений
- **Мода** — для категориальных
- **MICE** — множественная импутация

## Конструктор анализа

> **Главный инструмент** для проектирования статистического исследования

### Шаг 1: Подтверждение дизайна

После загрузки данных система покажет **авто-детекцию**:

- Группирующая переменная (например, «Группа»)
- Временные точки (например, «День 0», «День 7»)
- Конечные точки (endpoints)

Подтвердите или измените предложенные параметры.

### Шаг 2: Выбор переменных

| Роль | Назначение |
|------|------------|
| **Целевая (Target)** | Что измеряем (исход) |
| **Группа (Group)** | По чему сравниваем |
| **Ковариаты** | Дополнительные факторы |

### Шаг 3: Выбор тестов

Система предложит подходящие тесты:

| Тип данных | Тест |
|------------|------|
| Нормальные, 2 группы | t-test |
| Ненормальные, 2 группы | Mann-Whitney U |
| Нормальные, 3+ групп | ANOVA |
| Ненормальные, 3+ групп | Kruskal-Wallis |
| Парные измерения | Парный t-test / Wilcoxon |

### Шаг 4: Настройка параметров

- **α (альфа)** — уровень значимости (по умолчанию 0.05)
- **Post-hoc тесты** — Tukey, Bonferroni, Holm
- **Коррекция множественности** — FDR, Bonferroni

## Протокол анализа

### Создание протокола

1. Добавьте шаги анализа в конструкторе
2. Нажмите **«Запустить протокол»**
3. Дождитесь выполнения всех шагов

### Структура протокола

```
Протокол анализа
├── Шаг 1: Описательная статистика
├── Шаг 2: Проверка нормальности
├── Шаг 3: Статистический тест
└── Шаг 4: Post-hoc анализ
```

### Результаты

Каждый шаг содержит:

- **Таблицу результатов**
- **Графики** (box plot, bar chart)
- **AI-интерпретацию** (если включена)

## Вики статистики

### Как использовать

Откройте раздел **«Вики»** в меню.

### Доступные материалы

- **Термины** — p-value, effect size, power и др.

## Калькулятор размера выборки

### Когда использовать

**До сбора данных** — для планирования исследования.

### Входные параметры

- **Ожидаемый effect size** — малый/средний/большой
- **Мощность** — обычно 0.80 или 0.90
- **α** — обычно 0.05

### Результат

Минимальный размер выборки для каждой группы.

## Частые вопросы

### Почему нет результатов?

- Проверьте, выбраны ли целевая и группирующая переменные
- Убедитесь, что данные загружены корректно

### Почему AI-интерпретация пустая?

- Нужен API ключ для LLM (GLM, DeepSeek, Gemini)
- Проверьте настройки в `.env`

### Как изменить язык?

Интерфейс на русском. Язык отчётов — согласно шаблону.
