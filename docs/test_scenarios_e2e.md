# E2E сценарии: рабочий “от и до” флоу (без заглушек)

## Сценарий 1 — Happy Path: первичная конечная точка (UPDRS-3)

1) Загрузить `docs/Первичка для анализа работа.xlsx`
2) Дождаться scan report (колонки + статистики)
3) В Variable Workspace:
   - назначить Group = активное/плацебо
   - назначить Target = Δ(UPDRS-3) V6–V1 (или собрать дельту шагами prep)
4) Выбрать подходящий тест:
   - сравнение 2 групп по числовому outcome (t-test/Welch/Mann–Whitney в зависимости от предпосылок)
5) Запустить анализ
6) Убедиться:
   - результаты и графики отображаются
   - ошибки отсутствуют
   - доступна выгрузка отчёта

## Сценарий 2 — Happy Path: вторичные конечные точки

Повторить сценарий 1 для:

- Δ(DASS-21) V6–V1
- Δ(Epworth) V6–V1
- Δ(PDQ-39) V6–V1

## Сценарий 3 — Robustness: пропуски и типы

1) Выбрать outcome с пропусками
2) Запустить анализ без обработки пропусков
3) Ожидание: человеко-читаемая ошибка с конкретными действиями
4) Добавить prep шаг (удаление NA/приведение типов/импьютация — если доступно)
5) Повторно запустить анализ

## Сценарий 4 — Robustness: неверная групповая переменная

1) Назначить Group колонку с unique_count < 2
2) Ожидание: предупреждение в UI (не блокирующее выбор), но блокировка запуска/шаблона при критичности
3) Переназначить корректную Group
4) Запустить анализ

## Сценарий 5 — Safety summary

1) Подготовить/выбрать поля AE/SAE и АД (если присутствуют)
2) Сформировать:
   - частоты AE/SAE по группам
   - сравнение АД между группами/во времени
3) Ожидание: таблица + интерпретация, без пустых кнопок
