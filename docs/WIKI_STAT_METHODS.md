# Академическая справка по статистическим методам

Документ предназначен для встроенной базы знаний и описывает ключевые методы, используемые в протоколах анализа. Формат ориентирован на научные отчеты (Methods/Results/Discussion) и клинические исследования.

## Общие принципы

Статистический анализ должен быть воспроизводимым, обоснованным дизайном исследования и контролировать множественные сравнения. При наличии повторных измерений предпочтительно использовать смешанные модели или RM‑ANOVA/Friedman, а не независимые тесты.

## Описательная статистика

Описательная статистика используется для общей характеристики данных и баланса групп (Table 1). Рекомендуемые метрики:

- Количественные: среднее, SD, медиана, IQR, минимум/максимум, CI95%.
- Категориальные: частоты и проценты.
- Нормальность: Shapiro–Wilk (при n от 3 до 5000).

## Проверка предпосылок

Перед параметрическими тестами следует оценить:

- Нормальность распределения внутри групп (Shapiro–Wilk).
- Гомогенность дисперсий (Levene).
- При нарушении предпосылок применяются непараметрические аналоги.

## t‑test (независимые выборки)

Назначение: сравнение средних между двумя независимыми группами.

- H0: средние равны.
- H1: средние различаются.
- Предпосылки: нормальность, гомогенность дисперсий.
- Эффект: Cohen’s d, CI.
- Альтернатива при нарушениях: Mann–Whitney.

## Welch t‑test

Используется при нарушении гомогенности дисперсий.

- H0/H1 как у t‑test.
- Предпосылки: нормальность внутри групп.

## Парный t‑test

Назначение: сравнение двух связанных измерений (до/после).

- H0: средняя разница равна 0.
- H1: разница отличается от 0.
- Предпосылки: нормальность разностей.
- Эффект: Cohen’s d для парных разностей.
- Непараметрический аналог: Wilcoxon.

## Mann–Whitney U

Непараметрический тест для двух независимых групп.

- H0: распределения эквивалентны.
- Эффект: rank‑biserial correlation (RBC).

## Wilcoxon

Непараметрический парный тест.

- H0: медиана разностей равна 0.
- Эффект: RBC.

## ANOVA (однофакторный)

Назначение: сравнение средних между 3+ группами.

- H0: все средние равны.
- H1: хотя бы одна группа отличается.
- Предпосылки: нормальность, гомогенность дисперсий.
- Эффект: η² или partial η².
- Post‑hoc: Tukey или Games‑Howell (при неодинаковых дисперсиях).
- Непараметрический аналог: Kruskal–Wallis.

## Welch ANOVA

ANOVA при нарушении гомогенности дисперсий.

- Эффект: partial η².
- Post‑hoc: Games‑Howell.

## Kruskal–Wallis

Непараметрический аналог однофакторной ANOVA.

- H0: распределения одинаковы.
- Эффект: η²(H) или ε².
- Post‑hoc: Dunn с коррекцией.

## χ² (хи‑квадрат)

Назначение: связь между категориальными переменными.

- H0: независимость признаков.
- Эффект: Cramer’s V.
- При малых частотах предпочтителен Fisher exact.

## Корреляция

Pearson:

- Для количественных переменных при нормальности.
- Оценивает линейную связь.

Spearman:

- Для порядковых или при нарушении нормальности.
- Оценивает монотонную связь.

## Линейная регрессия

Назначение: моделирование количественного исхода.

- H0: коэффициенты равны 0.
- Метрики: R², коэффициенты, CI, p‑values.
- Предпосылки: линейность, нормальность остатков, гомоскедастичность.

## Логистическая регрессия

Назначение: моделирование бинарного исхода.

- H0: коэффициенты равны 0.
- Метрики: OR, CI, p‑values, pseudo‑R².
- Требует бинарного исхода; возможен one‑vs‑rest при многоуровневых классах.

## ROC‑анализ

Назначение: оценка дискриминации бинарного классификатора.

- Метрики: AUC, Youden index, чувствительность/специфичность.

## Повторные измерения

Repeated‑Measures ANOVA:

- Для 3+ временных точек с субъектным фактором.
- Предпосылки: нормальность, сферичность.

Friedman:

- Непараметрический аналог RM‑ANOVA.

Смешанные модели (Mixed Effects):

- Универсальный подход для лонгитюдных данных.
- Моделирует случайные эффекты (subject) и фиксированные эффекты (time, group, interaction).
- Рекомендуем при пропусках и неодинаковых интервалах.

## Кластерная корреляция

Используется в exploratory‑режиме для выявления кластеров взаимосвязанных признаков.

- Методы: Spearman/Pearson + иерархическая кластеризация (Ward).
- Результат: кластеры и карта корреляций.

## Множественные сравнения

При множественном тестировании требуется корректировка:

- FDR Benjamini–Hochberg (BH): стандарт для exploratory‑анализа.
- FDR Benjamini–Yekutieli (BY): более строгий при зависимости тестов.
- FDR BKY: компромисс между BH и BY.
- Bonferroni/Holm: строгие поправки при подтверждающем анализе.

## Рекомендуемое представление результатов

В отчете следует указывать:

- Название теста, статистику и p‑value.
- Эффект‑размер и его интерпретацию.
- Коррекцию за множественные сравнения (если применялась).
- Краткое заключение, связанное с гипотезой.

## Fisher Exact

Альтернатива χ² при малых ожидаемых частотах.

- H0: независимость категориальных переменных.
- Рекомендуется при ожидаемых частотах <5 в любых ячейках 2×2.
- Эффект: odds ratio (если вычисляется).

## Survival Analysis (Kaplan–Meier, Cox)

Используется при анализе времени до события.

- H0 (KM log‑rank): различий между кривыми выживаемости нет.
- H0 (Cox): коэффициенты модели равны 0.
- Метрики: медиана выживаемости, HR (hazard ratio), CI, p‑value.
- Требуется определение события и времени наблюдения.

## Responder Analysis

Доля пациентов, достигших клинически значимого улучшения.

- Зависит от заранее определенного порога (threshold).
- Тесты: χ² или Fisher для сравнения групп.
- Результат: абсолютные и относительные доли, OR, CI.

## Effect Size: интерпретация

Типичные пороги:

- Cohen’s d: 0.2 (малый), 0.5 (средний), 0.8 (большой).
- r: 0.1 (малый), 0.3 (средний), 0.5 (большой).
- η²: 0.01 (малый), 0.06 (средний), 0.14 (большой).

Пороговые значения ориентировочные и зависят от контекста.

## Коррекция множественных сравнений

Когда применять:

- При множестве параллельных гипотез (batch‑анализы).
- При post‑hoc анализе после ANOVA.

Рекомендации:

- Exploratory: FDR (BH, BKY).
- Confirmatory: Holm или Bonferroni.

## Модели и диагностика

При регрессиях следует оценивать:

- Мультиколлинеарность (VIF).
- Остатки и влияние выбросов (Cook’s D).
- Для логистической: разделимость, калибровка, AUC.

## Пропуски и чувствительный анализ

Стратегии:

- Простая импутация (median/mode) — допустима в exploratory‑режиме.
- Множественная импутация — для подтверждающего анализа.
- Чувствительный анализ: сравнить результаты с/без импутации.

## Подгруппы и взаимодействия

Подгруппный анализ требует контроля множественных сравнений и осторожной интерпретации.

- Подход: включение взаимодействий (Group×Subgroup) в модели.
- Альтернатива: отдельные сравнения внутри подгрупп (с FDR/Bonferroni).
- Рекомендуется заранее определить подгруппы.

## Машинное обучение (exploratory)

Используется для скрининга признаков или нелинейных связей.

- Методы: Random Forest, Gradient Boosting, SVM, kNN.
- Метрики: AUC (классификация), RMSE/MAE (регрессия).
- Обязательна валидация (train/test или CV).

## Снижение размерности и кластеризация

PCA:

- Используется для поиска латентных факторов.
- Описывает долю дисперсии, нагрузку признаков.

Кластеризация:

- Иерархическая (Ward) и k‑means.
- Отчет: число кластеров и интерпретация переменных.
