# COVID-19: Outcomes vs Glycemia (Detailed Prompt)

Use this prompt in ProtocolSorcerer/Copilot for dataset `docs/Общая таблица Ковид19.xlsx`.

```text
Ты выступаешь как клинический биостатистик и исследователь патофизиологии COVID-19.
Работай строго на данных датасета, без выдуманных переменных.
Цель: получить практически полезный вывод для ведения пациентов (риск неблагоприятного исхода) и патофизиологическое объяснение роли гликемии.

=== КЛИНИЧЕСКИЙ ВОПРОС ===
У госпитализированных пациентов с COVID-19:
1) Связана ли гликемия (при поступлении и в динамике) с летальным исходом?
2) Отличается ли эффект гликемии у пациентов с/без предшествующего СД2?
3) Является ли дисгликемия независимым предиктором после поправки на тяжесть состояния и ключевые лабораторные маркеры?

=== ПЕРЕМЕННЫЕ (используй реальные названия колонок) ===
Исход:
- `Исход` (допустимые значения нормализовать: "Мертв"/"мертв"=1, "Выписан"/"выписан"/"выписан "=0)
- при необходимости валидация дублями: `Исход.1`, `Исход.2`

Экспозиции по гликемии:
- `Глюкоза при поступлении`
- `Глюкоза последний результат`
- `Гипергликемия >11,1 дважды по результатам бх крови` (да/нет)
- `Сахарный диабет 2 типа перед госпитализацией (да/нет)` (да/нет)

Ковариаты/конфаундеры (по доступности):
- демография: `возраст`, `пол`
- тяжесть: `SpO2 %`, `qSOFA`, `NEWS2`
- воспаление/коагуляция/органная дисфункция: `СРБ1`, `СРБ 2`, `фибриноген1`, `фибриноген 2`, `Фибриноген V2`, `АЛТ1`, `АСТ1`, `креатинин1`, `АЛТ 2`, `АСТ 2`, `креатинин2`
- коморбидность: `Гипертоническая болезнь (да/нет)`, `Ожирение`, `Стадия ХБП1`

=== ШАГИ АНАЛИЗА ===
1) Data quality и cleaning:
- Показать долю пропусков для всех ключевых переменных.
- Явно описать правила очистки строковых категорий (регистр, пробелы, русские/латинские варианты).
- Привести таблицу соответствия "сырое значение -> нормализованное значение".

2) Описательная статистика:
- Таблица 1: общая когорта и стратификация по исходу (жив/умер).
- Для непрерывных: медиана [IQR] и/или mean±SD (по распределению), для категориальных: n (%).
- Для гликемии добавить клинические категории:
  - <7.8 ммоль/л
  - 7.8-11.1 ммоль/л
  - >=11.1 ммоль/л

3) Однофакторный анализ:
- OR/95% CI для каждой гликемической переменной относительно летального исхода.
- Для категорий гликемии показать p for trend.

4) Многофакторное моделирование (основной блок):
- Бинарная логистическая регрессия с исходом death.
- Базовая модель: гликемия + возраст + пол.
- Клиническая модель: + SpO2 % + NEWS2 (или qSOFA, если NEWS2 сильно неполный).
- Расширенная модель: + маркеры воспаления/коагуляции/почечной функции (по доступности и без перегрузки параметрами).
- Отдельно проверить:
  - `Глюкоза при поступлении`
  - `Глюкоза последний результат`
  - `Гипергликемия >11,1 дважды...`
- Проверить нелинейность эффекта глюкозы (restricted cubic spline или квадратичный член).
- Проверить взаимодействие:
  - гликемия * СД2 перед госпитализацией.

5) Анализ устойчивости (sensitivity):
- Complete-case и альтернативно модель с разумной импутацией (если реализуемо).
- Повторить модели без пациентов с известным СД2 (стресс-гипергликемия в "без диабета").
- Проверить влияние потенциальных выбросов (winsorization/robust подход) и сообщить, меняется ли вывод.

6) Качество модели:
- ROC-AUC, calibration (например, Brier score/калибровочный график).
- VIF/признаки мультиколлинеарности.
- Диагностика числа событий на параметр (EPV), чтобы не перегрузить модель.

=== ВЫВОДЫ ДЛЯ ПРАКТИКИ ===
Сформируй раздел "Практические решения":
1) Какой гликемический показатель сильнее связан с летальным исходом (при поступлении vs последний)?
2) Есть ли порог, при котором риск заметно растет?
3) Нужно ли по данным когорты усиливать мониторинг/коррекцию гликемии у пациентов без известного СД2?
4) Какие 2-3 клинически применимые правила стратификации риска можно предложить?

=== ПАТОФИЗИОЛОГИЯ (интерпретация) ===
Сделай отдельный раздел:
- возможные механизмы связи гипергликемии и плохих исходов (воспаление, эндотелиальная дисфункция, тромбовоспаление, иммунометаболические эффекты),
- почему эффект может отличаться у пациентов с и без СД2,
- почему "последняя глюкоза" может быть более сильным маркером исхода, чем "глюкоза при поступлении" (если это подтвердится).
Важно: раздел патофизиологии должен быть привязан к наблюдаемым данным, а не быть общим обзором.

=== ФОРМАТ РЕЗУЛЬТАТОВ ===
Верни:
1) Короткое executive summary (5-8 пунктов).
2) Таблицы:
- baseline table;
- однофакторные OR;
- многофакторные OR по 3 моделям;
- interaction table (СД2 * гликемия).
3) Графики:
- ROC curve главной модели;
- spline/эффект глюкозы на риск смерти;
- forest plot OR по ключевым предикторам.
4) Блок ограничений:
- пропуски, возможный selection bias, отсутствие части лабораторных данных, ретроспективный дизайн.
5) Финальное заключение:
- что именно в этих данных подтверждено, что вероятно, что остается неопределенным.

=== ОГРАНИЧЕНИЯ НА ПОВЕДЕНИЕ МОДЕЛИ ===
- Не подменяй отсутствие причинности причинными формулировками.
- Не игнорируй пропуски.
- Если статистически значимого эффекта нет, прямо так и напиши.
- Все числа и проценты рассчитывай из датасета; не используй внешние оценки.
```
