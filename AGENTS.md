## 🎯 ЦЕЛЬ ПРОЕКТА

Создать **"JAMOVI на стероидах"** — веб-приложение для статистического анализа биомедицинских данных.

### Область применения

- 🏥 Клинические исследования
- 🧬 Биохимия и молекулярная биология
- 💊 Фармакология
- 🔬 Биомедицинские науки в целом

### Что такое JAMOVI / JASP (для контекста)

- Бесплатные статистические программы
- Простой интерфейс: загрузил данные → выбрал тест → получил результат
- JASP: более гибкая настройка параметров тестов
- Таблицы с данными можно редактировать
- Результаты в красивых таблицах и графиках

### Чем наш проект ЛУЧШЕ JAMOVI/JASP

| Функция | JAMOVI/JASP | Наш проект |
|---------|-------------|------------|
| Установка | Нужно скачать | Веб-приложение |
| AI-рекомендации | ❌ | ✅ Какой тест выбрать |
| AI-интерпретации | ❌ | ✅ Автоматические заключения |
| Импутация пропусков | Базовая | MICE + 7 методов |
| Кастомизация тестов | JASP лучше | ✅ Как в JASP |
| Batch-анализ | ❌ | ✅ Протоколы |
| Effect size + интерпретация | Частично | ✅ С AI-объяснением |
| Экспорт | Ограничен | PDF/HTML/Word |

### 📊 Описательные статистики (обязательный минимум)

Каждый анализ должен включать:

| Метрика | Описание | Интерпретация AI |
|---------|----------|-----------------|
| N | Размер выборки | Достаточен ли для теста? |
| Mean ± SD | Среднее и разброс | — |
| Median [Q1, Q3] | Центр и межквартильный размах | — |
| Min, Max, Range | Диапазон | — |
| Skewness, Kurtosis | Форма распределения | Нормальное или нет? |
| Shapiro-Wilk p | Тест нормальности | p < 0.05 → не нормальное |
| **Cohen's d** | Размер эффекта (для сравнений) | 0.2=малый, 0.5=средний, 0.8=большой |
| **Eta-squared η²** | Размер эффекта (для ANOVA) | 0.01=малый, 0.06=средний, 0.14=большой |
| **r** | Размер эффекта (для корреляций) | 0.1=слабый, 0.3=средний, 0.5=сильный |
| **Odds Ratio** | Размер эффекта (для таблиц) | > 1 = риск выше, < 1 = ниже |
| 95% CI | Доверительный интервал | Если не включает 0 → значимо |

### Python (Backend)

```python
# ✅ ПРАВИЛЬНО
def calculate_cohens_d(group1: pd.Series, group2: pd.Series) -> float:
    """
    Calculate Cohen's d effect size for two groups.
    Returns value between 0 and infinity (0.2=small, 0.5=medium, 0.8=large).
    """
    pooled_std = np.sqrt((group1.var() + group2.var()) / 2)
    return abs(group1.mean() - group2.mean()) / pooled_std

# ❌ НЕПРАВИЛЬНО
def calc(g1, g2):
    s = np.sqrt((g1.var() + g2.var()) / 2)
    return abs(g1.mean() - g2.mean()) / s
```
