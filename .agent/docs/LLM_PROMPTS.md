# 🤖 LLM Prompts Library

> Шаблоны для генерации научного текста

---

## 📋 Общие принципы

### Стиль

- Академический, нейтральный
- Без bullet points (для основного текста)
- Связные переходы между абзацами
- Привязка к данным (p, ES, Δ%)
- Никаких упоминаний AI/LLM/модели

### Структура промпта

```
1. РОЛЬ: Кто ты (биостатистик, научный редактор)
2. КОНТЕКСТ: Информация об исследовании
3. ДАННЫЕ: Результаты анализа
4. ИНСТРУКЦИИ: Что делать
5. ФОРМАТ: Как оформить выход
```

## 📝 Discussion Section

```python
DISCUSSION_PROMPT = """
Ты — клинический биостатистик, автор раздела «Обсуждение» научного отчёта.

КОНТЕКСТ ИССЛЕДОВАНИЯ:
- Цель: {objective}
- Основная гипотеза: H₀: {h0} | H₁: {h1}
- Первичная конечная точка: {primary_endpoint}
- Дизайн: {study_design}

КЛЮЧЕВЫЕ РЕЗУЛЬТАТЫ:
{results_summary}

ИНСТРУКЦИИ:
1. Первый абзац — прямой ответ на основную гипотезу (принять/отклонить H₀)
2. Каждое утверждение привязано к статистике (p, ES, Δ%)
3. Обсуди клиническую значимость эффекта
4. Упомяни ограничения (размер выборки, множественные сравнения, коррекция)
5. Сравни с общепринятыми представлениями (без конкретных цитат)
6. 4-6 абзацев, 400-600 слов

ФОРМАТ:
- Связный текст без bullet points
- Академический русский язык
- Не упоминай AI/LLM/модель
"""
```

```python
RESULTS_PROMPT = """
Напиши раздел «Результаты» научной статьи на основе статистического анализа.

ДАННЫЕ:
{full_results_json}

ИНСТРУКЦИИ:
1. Начни с описательной статистики участников
2. Первичный показатель — отдельный абзац с подробностями
3. Вторичные показатели — кратко, основные находки
4. Для значимых результатов: p, ES, 95% CI
5. Упомяни незначимые результаты кратко

ФОРМАТ:
- Связный текст (таблицы отдельно)
- Ссылки на таблицы: "см. Таблицу 1"
- Числа: M±SD или Median (IQR)
- p-values: p < 0.001, p = 0.023, etc.
"""
```

## ⚠️ Промпты для обработки ошибок

### Нет значимых результатов

```python
NO_SIGNIFICANT_PROMPT = """
После коррекции на множественные сравнения значимых различий не выявлено.

Сформулируй интерпретацию:
1. Что это означает (не = "нет эффекта")
2. Возможные причины (мощность, вариабельность)
3. Наиболее обещающие сигналы (самые низкие p)
4. Рекомендации (увеличить выборку, изменить дизайн)

2-3 абзаца, академический стиль.
"""
```

### Множественные сравнения


## 🔌 Использование в коде

```python
# backend/app/llm/service.py
from .prompts.discussion import DISCUSSION_PROMPT

class LLMService:
    async def generate_discussion(
        self, 
        study_config: StudyConfig,
        results: AnalysisResults
    ) -> str:
        prompt = DISCUSSION_PROMPT.format(
            objective=study_config.objective,
            h0=study_config.hypotheses[0].h0,
            h1=study_config.hypotheses[0].h1,
            primary_endpoint=study_config.primary_endpoint,
            study_design=study_config.study_type.value,
            results_summary=self._format_results(results)
        )
        
        return await self.adapter.complete(prompt)
```
